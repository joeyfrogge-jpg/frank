# FRANK — web + Android APK

## Shared Explore (no Supabase)

1. Create a free account at https://jsonbin.io
2. Create a bin with body: `{"posts":[]}`
3. In FRANK **Settings**, paste **Bin URL** and **Master Key**
4. Save — web and APK share this feed
5. Viewers need **no key**. Only publishers need the key in Settings.

Videos are public Puter URLs. The bin stores metadata + URLs only.

## Download APK

1. GitHub repo → **Actions** → **Build FRANK APK** → **Run workflow**
2. Download artifact `frank-debug-apk` → install `app-debug.apk`
3. Enable **Install unknown apps** on Android if asked

Or: Chrome → **Add to Home screen** (PWA, no APK).

## Engine

Wan 2.7 via Puter (User-Pays). Same generate / library / Explore on website and APK.
